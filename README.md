🏠 **Hotel Room Booking Application**

📌 Project Overview
* A web-based application designed to manage hotel room bookings efficiently
* Allows users to search, book, modify, and cancel hotel rooms
* Provides secure user authentication and session management
* Supports real-time room availability tracking
* Handles booking details such as check-in/check-out dates, guest details, and payment status

🚀 Features
* User Login & Authentication
* Room Search & Availability Check
* Room Booking
* Booking Modification
* Booking Cancellation
* Booking History & Details
